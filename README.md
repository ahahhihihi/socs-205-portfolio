# Spatial analytics portfolio

Coursework for SOCS-SHU 205, *How Machines Map the Human World*, NYU Shanghai.

**Live site:** https://ahahhihihi.github.io/socs-205-portfolio/

## What is here

```
index.html        the front page: who you are, and a card for each lab
style.css         every colour, size and spacing rule on the site
labs/lab-0.html  lab entry template — copy this file for each new lab
labs/lab-01.html example lab entry with Soho cholera analysis
labs/media/      folder containing images for all labs
.nojekyll        tells GitHub Pages to serve the files exactly as written
```

No build step, no dependencies, nothing to install. Edit a file, commit, and
the change is live in about a minute.

## House rule

No external fonts, scripts, or CDNs. Everything loads from this repository, so
the site behaves the same on campus in Shanghai as it does anywhere else.
